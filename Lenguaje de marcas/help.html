Guía para Fabricar un Coche

Para construir un coche, hay un paso que siempre debe hacerse primero:

Comienza siempre por colocar la carrocería, ya que es la base de todo el coche.

Después de tener la carrocería, puedes ensamblar el resto de las partes.

Recuerda: el coche solo se puede enviar una vez que todas las partes estén colocadas. Asegúrate de revisar que no falte ninguna antes de enviarlo.
