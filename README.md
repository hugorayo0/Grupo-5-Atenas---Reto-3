# Fábrica de Vehículos

Este proyecto consiste en dos partes una pagina web y un programa de python

**Página web**

- Puedes realizar una simulación del proceso de producción de un coche
- Puedes realizar una encuesta sobre encuesta sobre derechos, contratos y condiciones laborales.
- Contiene un apartado FAQ con preguntas frecuentes sobre producción, control de calidad y transporte.

**Programa de python**

- Permite iniciar sesión como administrador
- Gestionar el inventario de piezas mediante el archivo JSON (piezas.json)
- Ver la distribución de la fábrica
- Realizar una simulación del proceso de producción mediante el archivo JSON (procesos.json) con verificación del montaje correcto del vehículo.
- Genera estadísticas de producción usando una base de datos SQLite.

# Tecnologías
- **Web**: HTML, CSS y JavaScript
- **Python**: Python 3.13
- **Archivos de datos**: JSON (para el inventario y proceso de producción)
- **Base de datos**: SQLite
